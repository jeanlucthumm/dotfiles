# Rosé Pine Dawn (base16)

The stylix scheme themeing kitty and everything else. Light variant.
Source of truth: `theme` in the nix config (currently `rose-pine`,
`darkMode = false` → `rose-pine-dawn.yaml` from base16-schemes).
